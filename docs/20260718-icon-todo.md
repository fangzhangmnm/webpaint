## 规则备忘

三分，无灰区：

| 类别 | 归属 | 例子 |
|---|---|---|
| **对象** | `assets/icons.svg` | 云、软盘、垃圾桶、图层 |
| **状态** | app CSS | 右上角标点、`aria-pressed`、accent 染色 |
| **纹理/装饰** | app CSS | 缩放抓手斜纹、透明棋盘格、取色器指针三角 |

后两类不产生 `<svg>`，所以不变量是绝对的：**sprite 区之外零内联 `<svg>`**，不需要豁免名单。

菜单项没有图标不是漏了——user 明确要求「宁可留空也不要硬凑」，留空走
`.menu-item-icon-blank`（占 18px 空位保持文字对齐，不画任何东西）。现在 6 项留空。
