## 升级步骤（手工，不进构建脚本）

```bash
# 1) 重新生成上游那部分。名字列表 = 我们实际用到的，看 assets/icons.svg 现有的 symbol id
python3 "../20260708 SVG Icons/extract-icons.py" assets/icons.svg <名字…> --overwrite

# 2) 把「本地追加」那一段贴回去
#    extract 会整份覆盖，它不认识我们本地加的东西。贴之前先看 git diff 确认要保留哪些。

# 3) 重新内联进 index.html
python3 tools/inline-sprites.py

# 4) 看上游到底改了什么
git diff assets/icons.svg
```

想知道库里有什么：`python3 "../20260708 SVG Icons/extract-icons.py" --list`

**这几步是人跑的，不在 `scripts/build.sh` 里，也不该进去。**
构建只认 `assets/icons.svg` 这一个本地文件。

   上游已经把 `cloud-modified` 退役了，注明「甲方改用 CSS 伪元素画那个点, 便于按状态换色」。

## 规则备忘

三分，无灰区：

| 类别 | 归属 | 例子 |
|---|---|---|
| **对象** | `assets/icons.svg` | 云、软盘、垃圾桶、图层 |
| **状态** | app CSS | 右上角标点、`aria-pressed`、accent 染色 |
| **纹理/装饰** | app CSS | 缩放抓手斜纹、透明棋盘格、取色器指针三角 |

后两类不产生 `<svg>`，所以不变量是绝对的：**sprite 区之外零内联 `<svg>`**，不需要豁免名单。

菜单项没有图标不是漏了——user 明确要求「宁可留空也不要硬凑」，留空走
`.menu-item-icon-blank`（占 18px 空位保持文字对齐，不画任何东西）。别把那些当待办。
