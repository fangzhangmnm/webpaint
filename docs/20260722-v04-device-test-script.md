## 阶段 0 · 烟囱（≈2 分钟；任何一步崩 → 停，交回 agent）

1. 开 dev PWA → 水印 **v0.4.10**（不对 = 部署没到，先别测）。
2. 图库开一张**已有云画** → 画一笔 → undo → redo → 保存 → 退图库。
3. 缩略图已更新且正确（S9 新缩略图链路）→ 重开，内容一致。

（这 3 步隐式覆盖：boot/store/打开、**GPU commit 基本面（每一笔都走新路径）**、
undo 栈、保存链、GL 合成缩略图。）

## 阶段 1 · 新建一张真画的一条龙（≈20 分钟；主战场，边创作边验收）

开 HUD（fps 面板），全程余光扫读数即可。新建 2048²：

1. **笔刷矩阵**（§10 根治点——盯每次**抬笔瞬间画面不许跳**，live=commit）：
   wash 线稿 → 橡皮修 → buildup 喷枪铺色 → 低不透明度叠加 → multiply 笔刷上阴影 →
   大笔刷甩一条长线（抬笔延迟感）。HUD：描边中 `sb0 shN`。
2. **图层全家**（§3）：+3 层、编组、组透明度、clip 层上色、锁α 改色、复制层（改一层另一层不动）、
   合并向下、显隐/重命名。undo 穿越只挑 3 个代表：编组、clip、合并。
3. **选区链**（§4）：套索圈选 → **选区内描边**（越界不许漏）→ 反选清除 → 魔术棒 → 扩/缩 →
   变换 lift→拖→旋→stamp→accept → **一次 undo 回整链**。
4. **液化**（§10 H7）：无选区推拉一把 → **圈个选区、把内容推出其原有内容边界**——越界那半必须
   跟着动（旧版半拉）→ bleed 三模式各推一下 → reconstruct 抹回。HUD：液化描边中 `sb` 恒 0。
5. **吸管**（§10）：composite 模式在「组内 + clip + multiply」叠加区取色 = 眼睛所见；
   layer 模式对比一次；棋盘背景开着再取一次。
6. **滤镜笔 + 调整**：模糊笔两笔；曲线拉动看 live → 应用 → undo。
7. **整 doc**（§6）：crop → 旋转 → 翻转，各 undo。
8. **出口**（§11）：导出 PNG（透明保留）、JPG（有底）、「仅当前层」选个 clip 层试 →
   存 .ora 退图库看缩略图（**这张画有组有 clip——缩略图必须和画布一致**）→ 重开一致 →
   开参考窗「镜像画布」画两笔（组/clip 显示对；镜像迟 ~0.3s 是有意节流，拍板项⑥顺手感受）。

## 阶段 2 · 韧性 + 集成（≈15 分钟；用一张扔了不心疼的测试画）

1. **autosave 灾难恢复**（§10 新机制）：画几笔**不保存** → 放着别动 3–4 分钟（真空闲，
   bg-jobs 才会跑）→ 强杀 PWA → 重开：恢复到 autosave 内容。
2. 切后台 30 秒回来（context-loss 自愈 + 压缩）；画面完好、能继续画。
3. **加密件**：开/画/存/缩略图正常；autosave 也 1 次。
4. 云同步往返一次 + 开一张 v438 旧 ora（无「新版本」误报）。
5. 顺手 30 秒：复制到剪贴板、打印预览弹出即可；Blender 推拉（环境不顺手就标 skip）。
6. 长 session 体感（阶段 1 已画了半小时）：发热/掉帧/显存 `!` 是否常亮，一句话即可。
